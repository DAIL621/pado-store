# PADO STORY Icon Guide

## Style

- Simple
- Rounded or outline
- Same visual weight within one section
- Avoid mixed emoji in production UI

## Trust Card Icon Text

Until a full icon set is installed, use short Korean text marks:

- 산: 산지
- 출: 출고
- 냉: 냉장
- 선: 선별
- 실: 실물
- 검: 검수

## Usage

- Icons support meaning; they do not replace labels.
- Every icon-only action needs an accessible label.
- Do not use playful icons where trust is more important than fun.
